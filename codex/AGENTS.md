# Rules riêng cho Codex

# Ngoại lệ ngôn ngữ khi học tiếng Anh
- Mặc định trả lời bằng tiếng Việt. Chỉ khi hook `ch-learn-english` xác nhận chế độ English đang bật cho chat hiện tại thì trả lời tiếng Anh theo phương pháp của skill; khi tắt, trở lại tiếng Việt.

# Cách gọi công cụ
- Đọc file `SKILL.md` để dùng skill, bắt đầu bằng `using-superpowers` theo quy trình chung.
