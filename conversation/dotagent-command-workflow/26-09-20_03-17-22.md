# Agent

Đúng. `AGENTS.md` là file rules/instructions: agent tự đọc nó theo thư mục làm việc và áp dụng các quy tắc chung.

`SKILL.md` thì khác: đó là workflow chuyên biệt, thường được gọi rõ ràng bằng `$tên-skill`.

Trong hệ của bạn:

- `G:\dotagents\codex\AGENTS.md`: rules source cho Codex.
- `C:\Users\royal\.codex\AGENTS.md`: rules đã cài vào Codex.
- `shared\skills\...\SKILL.md`: nội dung các skill.

Bản tương đương bên Claude Code là `CLAUDE.md`.
