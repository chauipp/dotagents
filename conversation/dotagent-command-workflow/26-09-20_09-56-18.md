# Agent

Đúng. Hiện có hai skill liên quan:

- `writing-skills`: dùng khi tạo, sửa hoặc kiểm thử một skill. Nó áp dụng tư duy TDD cho tài liệu: viết pressure test trước, quan sát agent vi phạm hoặc lách quy tắc, viết skill tối thiểu, rồi kiểm tra và đóng các loophole.
- `skill-creator`: dùng để thiết kế cấu trúc và nội dung một skill Codex đúng chuẩn, gồm `SKILL.md`, frontmatter, `agents/openai.yaml`, scripts, references và assets khi cần.

Với workflow dựng phòng multi-agent mà bạn mô tả, nếu muốn biến nó thành skill dùng lại nhiều lần thì nên dùng `writing-skills` làm quy trình kiểm thử chính, đồng thời dùng `skill-creator` để tạo hoặc cập nhật cấu trúc skill.
