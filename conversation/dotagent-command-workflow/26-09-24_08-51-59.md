## User
hiện tại install.sh đang có các loại install nào ấy nhỉ, nói ra cho tôi xem đã đúng ý tôi chưa

## Assistant
Trong bản `install.sh` ở worktree `.worktrees/single-skills-catalog-visible`, các kiểu cài hiện có là:

| Phạm vi | Lệnh | Ý nghĩa |
|---|---|---|
| Global, tự dò | `./install.sh` | Cài cho agent nào có thư mục config sẵn; có cả Claude và Codex thì cài cả hai. |
| Global, chọn agent | `./install.sh --claude`, `--codex`, hoặc `--all` | Chỉ Claude, chỉ Codex, hoặc cả hai. |
| Một project | `./install.sh --project [DIR]` | Cài vào project; bỏ `DIR` thì dùng thư mục hiện tại. Mặc định cài cả hai agent. |
| Một project, chọn agent | `./install.sh --project DIR --claude`, `--codex`, hoặc `--all` | Chỉ agent được chọn hoặc cả hai. |

Global là chế độ mặc định, không có cờ `--global`; project dùng `--project`. `--check` ghép được với hai phạm vi để kiểm tra mà không ghi file. Các lệnh cài thật cũng cập nhật rules của agent được chọn cùng skills: Claude nhận 28 skill, Codex nhận 30 skill, gồm hai profile map chỉ dành cho Codex.

Có một lỗi cần sửa trước khi coi các tùy chọn là hoàn chỉnh: `--rules-only` chỉ được tôn trọng trong chế độ project. Với global, code vẫn chép skills và cập nhật config dù có cờ này. Phần mô tả CLI cũng hiện mới ghi ví dụ `--rules-only` cho project.

Như vậy các lựa chọn global/project và Claude/Codex/all đã có theo ý bạn; cần sửa lỗi `--rules-only` của global.
