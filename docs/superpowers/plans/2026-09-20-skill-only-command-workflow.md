# Skill-only Command Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task.

**Goal:** Make `no-clarify`, `clear-conversation`, and `compact-conversation` available as explicit `$` skills for every supported agent, without command-specific behavior in `AGENTS.md` or `CLAUDE.md`.

**Architecture:** Keep each workflow in the shared `SKILL.md` directory with explicit-only `agents/openai.yaml` metadata. Remove only the corresponding action triggers from both agent rules files; retain general conversation logging rules. Update installer tests and documentation so the kit has one logical source of behavior. For an existing unmanaged agent installation, add only these three non-colliding workflows and preserve unrelated user-authored skills.

**Tech Stack:** Markdown, YAML metadata, Bash installer test assertions, PowerShell validation on Windows.

## Global Constraints

- All user-facing rules remain Vietnamese where the existing kit requires it.
- `$` skills must remain explicit-only (`allow_implicit_invocation: false`).
- Source skills live in `shared/skills/`; installed copies are deployment artifacts under the agent config directory.
- Do not alter unrelated worktree, Git identity, UI verification, or conversation-retention rules.
