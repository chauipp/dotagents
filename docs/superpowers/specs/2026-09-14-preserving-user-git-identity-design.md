# Thiết kế: bảo toàn danh tính Git của người dùng

## Mục tiêu

Mọi thay đổi do agent hỗ trợ phải giữ danh tính Git hiện có của người dùng và không tự tạo dấu vết attribution của agent/AI trong mã nguồn, commit, push hoặc metadata liên quan.

## Phạm vi

Thay đổi áp dụng cho bộ dotagents cài toàn cục hoặc theo dự án:

- Một skill dùng chung, được cài cho Claude Code và Codex, hướng dẫn kiểm tra identity Git, nội dung staged và metadata trước commit/push.
- Rule ở cả `claude/CLAUDE.md` và `codex/AGENTS.md` để yêu cầu này luôn được nạp, kể cả khi agent chưa chủ động tìm skill.
- Regression test xác nhận installer phân phối skill và rule mới.

## Hành vi bắt buộc

1. Agent không được đặt, sửa hoặc ghi đè `user.name`/`user.email`; không dùng `git commit --author`; không dùng tài khoản bot hay danh tính của agent.
2. Trước khi commit, agent phải đọc `git config user.name` và `git config user.email`. Nếu một trong hai thiếu hoặc rỗng, agent dừng trước commit/push và yêu cầu người dùng cấu hình hay xác nhận danh tính phù hợp.
3. Agent không được thêm hoặc giữ các attribution không phải nội dung kỹ thuật, như tên agent/model, `Generated by …`, `AI-assisted`, bot identity hoặc trailer đồng tác giả của AI/agent, trong code, commit message, template, PR/changelog hay metadata do agent tạo.
4. Agent phải kiểm tra staged diff, commit message/template và trailer trước commit/push. Nếu phát hiện dấu vết bị cấm, agent phải loại bỏ nó hoặc thay bằng mô tả kỹ thuật trung tính trước khi tiếp tục.
5. Quy tắc không cho phép mạo danh: agent không tự chọn danh tính thay thế, không suy đoán email của người dùng và không đổi Git config để làm commit qua được.

## Thiết kế skill

Skill tên `preserving-user-git-identity`. Tên và mô tả phải giúp agent tìm được skill khi chuẩn bị commit, push, sửa metadata, hoặc khi thấy attribution/co-author/bot identity. Nội dung gồm quy trình kiểm tra, bảng dấu vết bị cấm, điều kiện dừng khi thiếu identity, kiểm tra trước push và các rationalization thường gặp.

Skill chỉ yêu cầu bỏ attribution do agent tự tạo; không được xóa thông tin bản quyền, license, tác giả, hoặc provenance do dự án/người dùng đã có khi không được yêu cầu.

## Kiểm thử

`tests/install.sh` sẽ kiểm tra nguồn skill tồn tại, skill được copy vào cả `.claude/skills` và `.codex/skills` khi cài theo dự án, và hai file rules đã cài có câu neo cho quy tắc bảo toàn identity.

## Ngoài phạm vi

- Không thay đổi Git config toàn cục/cục bộ của người dùng.
- Không tự push hay thay đổi lịch sử commit hiện có.
- Không làm sạch nội dung attribution đã tồn tại nếu người dùng không yêu cầu.
